# Security Policy

## Supported Versions

Security fixes target the latest published Chrome and Microsoft Edge extension versions and the current `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Email `ianloe666@gmail.com` with the subject `[Security] WebSocket DevTools` and include:

- A clear description of the issue and its impact
- Steps or a minimal example that reproduces it
- The affected browser and extension version
- Any suggested mitigation, if available

We will acknowledge the report, investigate it, and coordinate disclosure after a fix is available.
